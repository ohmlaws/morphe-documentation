effects using **before and after screenshots**.

> patch settings. For the complete and up-to-date list of patches, options,
> and supported application versions, see the

## 📸 Before and after screenshots

Each documented setting can include screenshots showing its effect.

### Before

The setting is **disabled**.

### After

The setting is **enabled**.

Screenshots should preferably be captured using the same:

- Application version
- Device

This makes the difference between the disabled and enabled states easier
to identify.

---

## 📝 Contributing

If a patch setting is not documented yet, you can contribute by adding:

- A description of what the setting does
- Where the setting can be found
- A **before** screenshot with the setting disabled
- An **after** screenshot with the setting enabled
- Any relevant notes or limitations

For consistency, follow the existing structure used by the other patch
settings documentation.
